## V0723 核心規格摘要

### 常態任務（每月上限 300 分）

- **提交／回覆時間為加分項目**，越早完成越有優勢
- 任務**不定時**透過 LINE 官方帳號發布，請**即時關注**

| 任務 | 積分 |
|------|------|
| 品牌隨堂考 | 100 |
| 客人推薦照片 | 100 |
| 新品陳列照片 | 100 |

積分兌換：100 分→1 張抽獎券｜200 分→2 張｜300 分以上→3 張抽獎券

### 每月排行（統一超商商品卡）

- 依積分排行，100～500 元商品卡（非禮券）
- 需當月完成至少 1 項任務

### 雙月抽獎

- 8–9 月累積 → 10 月抽（15 位 × 1,000 元）
- 10–11 月累積 → 12 月抽（15 位 × 2,000 元，10/1 起公告）
- 抽完後抽獎券重新計算

### 拜訪任務

- LINE 上傳合照，每月 20 日審核
- 每完成一間簽約店可獲抽獎券
